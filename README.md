## Agentic Process Orchestration

This Repository contains the implementations and supplementary material for the paper "Engineering of Agentic Orchestrations: Frames, Properties, Implementation, and Assessment".


### Literature Review

The Literature Review folder contains the supplementary material considering the conducted literature Review


### Scenarios

The implementation for the three scenarios can be found in the folders BloodDonationExample, IdeationScenario and LightingScenario. Each of the folder contains a own README file for more detailed explanations. 

The evaluation scripts are included within the scenario folders. The Traceability evaluation is in the Lighting folder, The Reproducibility is in the Ideation folder.
